# AI 策略助手使用说明

## 功能概览

AI 策略助手位于“策略”页面右侧，支持：

- 对话式描述策略需求
- 自动生成符合 QTsys 模板的可执行策略代码
- 自动校验 `initialize(context)` / `handle_data(context)` 结构
- 结合系统内最近新闻作为市场上下文
- 一键保存到策略库，随后直接进入回测与分析

## 配置步骤

1. 打开“设置”页面
2. 在“大模型配置”中填写：
   - `API Key`
   - `接口地址`
   - `模型名称`
3. 点击“保存设置”

说明：

- 系统按 OpenAI 兼容 `Chat Completions` 方式调用模型
- 若填写的是根路径，系统会自动尝试常见兼容端点
- 若返回 404/403，请优先检查服务商给出的真实接口地址

## 使用流程

### 1. 打开策略工作台

进入“策略”页面后：

- 左侧是已有策略库
- 中间是当前代码编辑器
- 右侧是 AI 策略助手

### 2. 输入需求

可以直接描述：

- 目标市场：如“沪深300”“中证500”
- 策略风格：趋势、均值回归、量价、动量、多因子
- 风险要求：低换手、单股仓位上限、止损、止盈
- 优化方向：如“优化当前策略”“加入风控”“减少回撤”

示例：

- `生成一个适合沪深300的趋势跟随策略，要求单股仓位不超过20%`
- `优化当前策略，加入更明确的止损和仓位控制`
- `生成一个偏稳健的中证500均值回归策略，尽量降低换手`

### 3. 生成草稿或直接保存

- `生成草稿`：只把 AI 输出写入中间编辑器，方便继续修改
- `生成并保存`：直接保存到策略库，可马上用于回测

### 4. 回测与分析

策略保存后可直接在“回测”页面中选择该策略，执行：

- 单次回测
- 参数优化
- Walk-Forward 验证
- 后续组合分析

## AI 助手的内置能力

当前版本内置以下能力：

- **模板约束**：强制输出 QTsys 可执行代码
- **市场快照**：读取系统内最近新闻作为上下文
- **量化设计**：补全信号、仓位、调仓、退出规则
- **风险复核**：本地校验代码结构，不通过时自动修复一次

## 常见问题

### 1. 为什么提示模型接口 404？

这通常表示你填写的地址不是实际的 OpenAI 兼容端点。请确认：

- 是否应填写完整的 `/v1/chat/completions`
- 或者是否应填写服务商要求的根路径

### 2. 为什么生成后没有保存到策略库？

只有点击“生成并保存”才会直接落库；“生成草稿”只会更新当前编辑器内容。

### 3. 为什么 AI 生成失败？

常见原因：

- 模型接口地址错误
- API Key 无效
- 网络无法访问模型服务
- 返回内容不是有效 JSON

### 4. AI 生成的代码能直接运行吗？

系统会先做本地模板校验；如果结构不符合要求，会自动尝试修复一次。修复后仍失败时，接口会直接报错，不会把无效代码写入策略库。
