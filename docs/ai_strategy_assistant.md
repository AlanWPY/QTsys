# AI 策略助手使用说明

## 功能概览

AI 策略助手位于“策略”页右侧，支持：

- 对话式描述策略需求
- 自动生成符合 QTsys 模板的可执行策略代码
- 自动校验 `initialize(context)` / `handle_data(context)` 结构
- 结合系统中的新闻、因子与策略上下文生成更可用的草稿
- 一键保存到策略库，并继续进入回测分析

## 配置步骤

1. 打开“设置”页
2. 在“大模型配置”中填写：
   - `API Key`
   - `接口地址`
   - `模型名称`
3. 点击“保存设置”
4. 点击“测试模型连接”确认可用

说明：

- 系统兼容 OpenAI 风格接口
- 若填写的是服务根路径，系统会尝试补齐常见兼容端点
- 若返回 `404/403`，请优先核对服务商要求的真实接口路径

## 通用配置建议

- `接口地址`：填写服务商文档给出的标准 API 根路径或兼容路径
- `模型名称`：填写当前 Key 实际开通的模型，不要只按网页展示名称猜测
- `API Key`：仅保存在本地数据库中，系统会以加密形式落库

## 使用流程

### 1. 打开策略工作台

进入“策略”页后：

- 左侧是策略库
- 中间是策略编辑器
- 右侧是 AI 策略助手

### 2. 输入需求

可直接描述：

- 目标市场：如沪深300、中证500、上证50
- 策略风格：趋势、均值回归、动量、多因子、量价
- 风险要求：低换手、单股仓位上限、止损、止盈
- 因子要求：是否直接调用系统因子库

示例：

- `生成一个适合沪深300成分股的低换手趋势策略，限制最大单股仓位 10%`
- `生成一个调用系统因子库的多因子轮动策略，股票池使用中证500`
- `优化当前策略，补充止损、持仓上限和调仓频率约束`

### 3. 生成草稿或直接保存

- `生成草稿`：仅写入编辑器，便于继续修改
- `生成并保存`：直接落库，随后可立即回测

### 4. 回测与分析

策略保存后可直接进入“回测”页执行：

- 单次回测
- 参数优化
- Walk-Forward 验证
- 历史对比与组合分析

## AI 助手内置能力

- 模板约束：强制输出 QTsys 可执行代码
- 因子联动：可直接调用系统中的因子接口
- 市场上下文：可读取系统中的新闻与研究上下文
- 本地校验：生成后先做模板和结构校验，不通过时自动尝试修复

## 常见问题

### 1. 为什么返回 404？

通常说明接口地址不是实际兼容端点。请检查：

- 是否应填写完整的 `/v1/chat/completions`
- 是否应填写服务商要求的根路径而非网页地址

### 2. 为什么生成后没有保存到策略库？

只有点击“生成并保存”才会直接落库；“生成草稿”只会更新当前编辑器内容。

### 3. 为什么 AI 生成失败？

常见原因：

- 接口地址错误
- API Key 无效
- 当前网络无法访问模型服务
- 返回内容不是有效结果

### 4. AI 生成的代码能直接运行吗？

系统会先做本地模板校验；结构不符合要求时会自动修复一次。修复失败时会直接报错，不会把无效代码写入策略库。
