# 交付摘要

## 本轮核心交付

### 因子看板能力增强
- 支持系统股票池：中证500、沪深300、上证50、中证1000
- 支持自定义股票池：搜索、加入、命名、保存、复用
- 支持自定义回测时间区间
- 支持停止分析
- 支持失败因子重试
- 支持分析日志与阶段进度展示

### 分析性能优化
- 历史行情优先复用缓存
- 通过覆盖区间元数据加快增量检查
- 对缺失行情执行增量更新，而非每次全量检查
- 因子分析阶段采用并行执行
- 完整历史批次可直接复用，避免重复计算

### 前端交互优化
- 自定义股票池移入独立管理入口，减少主界面拥挤
- 因子收益总览支持滚动查看完整结果
- 正负收益采用颜色区分
- 因子详情页支持多分位收益曲线、区间切换、公式和经济含义展示
- 分析过程页支持查看日志、失败因子与当前批次状态

### 稳定性修复
- 修复配置保存与 Token 持久化问题
- 修复股票池选择被状态轮询覆盖的问题
- 修复停止任务后的状态与结果刷新问题
- 修复失败因子重试重复写入问题
- 修复相关性计算中的无效除法告警

## 当前建议使用方式

1. 先在“设置”中保存 `Tushare Token`
2. 在“因子看板”中保存并测试 MySQL 连接
3. 先用系统股票池进行全量扫描
4. 根据收益、IC、IR、覆盖率筛选目标因子
5. 再切换自定义股票池做二次验证
6. 对失败因子使用重试功能，而不是整批重跑
