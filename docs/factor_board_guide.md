# 因子看板使用指南

## 1. 功能目标

因子看板用于批量评估 Alpha191 因子在真实市场数据上的表现，帮助研究者判断因子当前是否仍具备解释力、区分度和可交易性。

当前版本支持：

- 真实 Tushare 数据分析
- 系统股票池与自定义股票池
- 自定义回测时间区间
- 行情缓存复用与增量更新
- 分析中止
- 失败因子重试
- 因子总览、详情、公式、经济含义、持仓与多分位曲线

## 2. 使用前准备

### 2.1 配置 Tushare Token

先进入“设置”页，保存可用的 `Tushare Token`。

若 Token 未保存，因子看板无法启动真实分析。

### 2.2 配置 MySQL

进入“因子看板”页，在“数据库连接”区域填写：

- 主机
- 端口
- 用户名
- 密码
- 数据库名

然后按顺序执行：

1. 点击“测试连接”
2. 确认通过
3. 点击“保存配置”

说明：

- 系统主库仍为 SQLite
- MySQL 仅用于因子看板的行情缓存和结果存储

## 3. 分析参数说明

### 3.1 回测天数 / 时间区间

你可以通过开始日期和结束日期控制回测窗口。若不手动指定完整区间，系统会按回测天数推导默认窗口。

### 3.2 股票池类型

支持两类股票池：

- 系统股票池：中证500、沪深300、上证50、中证1000
- 自定义股票池：用户保存的股票集合

### 3.3 自定义股票池

点击“管理自定义股票池”后可进入独立管理界面：

1. 搜索股票代码或名称
2. 将目标股票加入股票池
3. 输入股票池名称和说明
4. 保存股票池
5. 返回主界面选择该股票池进行分析

自定义股票池会持久化保存到数据库，可重复复用。

## 4. 标准使用流程

### 步骤 1：进入因子看板

打开顶部导航中的“因子看板”。

### 步骤 2：完成数据库配置

若是首次使用，先在“数据库连接”区域保存 MySQL 连接。

### 步骤 3：选择分析参数

在“分析参数”区域完成以下设置：

- 回测区间
- 股票池类型
- 具体股票池

### 步骤 4：开始分析

点击“开始分析”。系统会依次执行：

1. 校验参数和配置
2. 获取交易日历
3. 确定股票池成分
4. 检查是否可复用历史批次
5. 检查本地 / MySQL 缓存覆盖范围
6. 仅对缺失区间执行增量行情获取
7. 并行计算 Alpha191 因子
8. 保存结果、日收益和持仓明细

### 步骤 5：查看分析过程

在“分析过程”区域可看到：

- 当前阶段
- 当前批次号
- 已保留结果数
- 实时日志
- 失败因子列表

如果任务运行时间较长，可通过日志确认当前卡在哪个阶段。

### 步骤 6：必要时停止分析

点击“停止分析”可请求中止当前任务。

说明：

- 已完成的结果会保留
- 已落库结果不会丢失
- 停止后可继续查看已完成部分的结果

### 步骤 7：重试失败因子

若本轮存在失败因子，可直接点击“重试失败因子”。

系统会：

- 复用当前批次
- 仅重跑失败因子
- 保留已成功的历史结果
- 更新失败列表和日志

## 5. 结果查看

## 5.1 因子收益总览

在“因子收益总览”区域中可查看每个因子的：

- 最大超额收益
- 最小超额收益
- IC 均值
- IR
- 覆盖率
- 换手率
- 最新交易日

你可以：

- 搜索因子名称
- 按指标排序
- 仅看正收益因子
- 仅看高 IC 因子
- 收藏重点因子

## 5.2 因子详情

点击任意因子后，可进入详情界面查看：

- 多分位收益曲线
- 区间切换器
- 最新绩效快照
- 因子简介
- 经济含义解释
- Alpha191 公式
- 最新持仓

## 5.3 如何理解关键指标

### 最大超额收益

表示最高分位组合相对于基准的超额表现，通常用于观察因子的多头有效性。

### IC 均值

表示因子排序与未来收益排序的一致性，越高通常说明横截面预测能力越强。

### IR

表示 IC 的稳定程度。IR 越高，说明因子不仅有效，而且稳定。

### 覆盖率

表示在每个交易日，实际可参与分位排序的股票占股票池成分的比例。覆盖率过低时，结果可信度会下降。

### 换手率

表示分位组合调仓频率和交易强度。换手率过高时，需要警惕交易成本侵蚀。

## 6. 性能与缓存机制

当前因子看板已做以下优化：

- 历史行情优先从缓存读取
- 使用元数据记录股票覆盖区间，避免每次全量检查
- 仅对缺失区间做增量获取
- 分析阶段使用并行执行
- 历史完整批次可直接复用
- 停止任务后保留已完成结果

这意味着：

- 首次跑一个新股票池会较慢
- 第二次跑相同股票池和相近区间通常会明显更快

## 7. 常见问题排查

### 7.1 点击开始分析无反应

检查：

- `Tushare Token` 是否已保存
- MySQL 是否已测试通过
- 是否已有任务在运行
- 自定义股票池是否为空

### 7.2 分析卡在行情阶段

通常是以下原因：

- 首次缓存建立
- 股票池较大且历史区间较长
- 外部数据接口返回较慢

此时优先看“分析过程”中的日志是否持续更新。

### 7.3 某些因子计算失败

系统会把失败因子列在“失败因子”区域。可先查看日志，再使用“重试失败因子”。

### 7.4 结果和预期不一致

优先检查：

- 股票池是否选对
- 时间区间是否选对
- 是否复用了旧批次
- 基准是否随股票池正确切换

## 8. 建议使用方式

对于研究流程，建议按以下顺序使用：

1. 先选系统股票池做全量扫描
2. 根据超额收益、IC、IR 做初筛
3. 收藏重点因子
4. 进入详情查看多分位曲线和持仓
5. 再切换到自定义股票池复核因子稳健性
6. 最后将有效因子转入后续策略或组合研究
