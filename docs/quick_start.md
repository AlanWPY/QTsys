# 快速开始

## 环境要求

- Python 3.12
- 可用的 `Tushare Token`
- 若使用因子看板，需要 MySQL 5.7+ 或 8.x

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动系统

```bash
python main.py
```

浏览器打开 `http://127.0.0.1:8000`

## 首次配置

1. 打开“设置”页面
2. 填写并保存 `Tushare Token`
3. 如需使用因子看板，打开“因子看板”页面
4. 填写 MySQL 连接信息并测试连接
5. 保存数据库配置

## 最短使用路径

### 策略回测

1. 创建或选择策略
2. 选择标的、区间和参数
3. 运行回测并查看结果

### 因子看板

1. 进入“因子看板”
2. 先保存 MySQL 连接
3. 选择股票池和回测区间
4. 点击“开始分析”
5. 在“分析过程”中查看进度、日志和失败因子
6. 分析完成后在“因子收益总览”中查看结果
7. 点击具体因子进入详情页查看收益曲线、公式和说明

## 常见问题

### 无法获取数据

优先检查 `Tushare Token` 是否有效，以及网络是否可访问 Tushare。

### 因子看板无法保存结果

优先检查 MySQL 连接是否测试通过，且数据库账户具备建表和写入权限。

### 首次分析很慢

首次需要建立本地缓存。后续同一股票池会优先复用缓存或只做增量更新。
